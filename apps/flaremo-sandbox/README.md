# FlareMo (sandbox build)

This entry exists only to exercise the sandbox build path of the paid tiers, and
will be removed. It installs the same pinned commit of
[realchendahuang/FlareMo](https://github.com/realchendahuang/FlareMo) as the
`flaremo` entry, but the app is built in your own account by the sandbox Worker
instead of by CI, so it needs Workers Paid and sandbox builds enabled.

For what the app does and what the install creates, see the `flaremo` entry.
